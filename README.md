# VI Community Hub

A fan-made GTA VI-themed community directory starter.

## Features
- GTA VI-inspired neon Vice City color palette
- Responsive landing page
- AFK account directory with search and platform filters
- Live-style status cards
- Countdown to November 19, 2026
- Mobile responsive layout
- Ready for GitHub + Vercel/Netlify deployment

## Run locally
```bash
npm install
npm run dev
```
